首次使用：粘贴 GitHub Token

  1. 手机浏览器打开 github.com 并登录
  2. 右上角头像 → Settings → 最底部 Developer settings
  3. Personal access tokens → Fine-grained tokens → Generate new token
  4. Repository access 选 Only select repositories，只勾 muse-chat
  5. Permissions 里 Issues 设为 Read and write，生成后复制 token
token 只保存在这台手机的浏览器本地，不会发给任何第三方。仓库是私有的，只有你能看到聊天内容。
